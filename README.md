# 心動小鎮助手（heartopiaHelper）

《Heartopia 心動小鎮》的自動化輔助工具，看畫面找到按鈕，自動幫你點擊與操作，支援電腦版遊戲與 Android 模擬器（僅限 Windows）。

## 功能

### 主要功能

- **料理**：自動開始烹飪、收料理，可設定份數；另有安全模式、五星停止、萬能食材、神奇調料。
- **釣魚**：自動拋竿、收竿，並定時噴香水、丟誘魚器、丟維修盒、吃食物，也可以用模擬器帳號同時在背景釣魚。
- **採集**：定時對著植物或樹木連按互動鍵，分「無工具」與「有工具」兩種；有工具可定時丟維修盒、吃食物。

### 更多

- **拼圖**：自動記下參考圖，再把碎片拖到對的位置，支援 36、64、100 片。
- **逗貓**：站在貓咪旁邊，自動點爪印開始逗貓，小遊戲看到貓耳泡泡就點對應的按鈕，結束後按確定再來一輪。
- **雪雕**：自動點雪花、放置、開始、完成；可勾選「吃食物」，體力不足時自動吃。
- **沙雕**：自動擺放基座、玩指針小遊戲、選題目的正確選項，基座用完自動停止；可勾選「吃食物」，體力不足時自動吃。
- **南瓜雕刻**：自動擺放、雕刻、收取，南瓜用完自動停止；可勾選「吃食物」，體力不足時自動吃。

### 小工具

- **拔草提醒**：農作物長草倒數計時，時間到跳桌面通知，不會操作遊戲，可與其他功能同時使用。

## 下載與安裝

1. 到 [Releases](https://github.com/jill83123/heartopiaHelper/releases) 下載最新版的 `heartopiaHelper_vX.Y.Z.zip`。
2. 解壓縮到任意資料夾，執行裡面的 `heartopiaHelper.exe`，不用安裝。
3. 有新版時程式上方會提示（也可以到「設定」分頁按「檢查更新」），按「立即更新」就會自動下載並重新啟動，設定不會被覆蓋。

## 開始使用

1. 開啟遊戲後，電腦版到「設定」分頁的「前景設定」、模擬器到「背景設定」，確認解析度或模擬器連線（見下方）。
2. 到想用的功能分頁，先點「注意事項」看開始前要準備什麼，料理需要先按「選取範圍」，框住鍋子、火、手套、計時器等圖示會出現的位置；其他功能不用選範圍。
3. 按「開始」，設定不完整時會跳出視窗說明原因，不會啟動。
   - 同一時間只能執行一個功能（拔草提醒除外）。
   - 開始後會跳出置頂的懸浮日誌，任務結束後可按 × 收起，顯示位置與是否自動關閉可以在「設定 > 一般設定」調整。
4. 要停止時按「停止」，或按停止鍵（預設 `F8`，可在設定分頁改）。

## 前景模式與模擬器模式

| | 前景模式 | 模擬器模式 |
| --- | --- | --- |
| 適用 | 電腦版遊戲 | BlueStacks、MuMu、雷電、夜神等模擬器（經 ADB） |
| 視窗 | 遊戲須在最上層，不能被其他視窗蓋住 | 可被其他視窗蓋住 |
| 原理 | 截取畫面、模擬滑鼠點擊 | ADB 截圖與點擊 |

各功能支援的模式：

| 功能 | 前景模式 | 模擬器模式 |
| --- | :---: | :---: |
| 料理 | ✅ | ✅ |
| 釣魚 | ✅ | ✅ |
| 採集 | ✅ | ✅ |
| 拼圖 | ✅ | ❌ |
| 逗貓 | ✅ | ❌ |
| 雪雕 | ✅ | ✅ |
| 沙雕 | ✅ | ❌ |
| 南瓜雕刻 | ✅ | ❌ |
| 拔草提醒 | 不適用 | 不適用 |

料理、雪雕、採集的分頁各有一個「操作模式」下拉選單，三者共用，改任何一個其他兩個會跟著變，釣魚的「前景定時」固定用前景模式，「背景定時」固定用模擬器。

### 前景模式

- 運行中請讓遊戲保持在最上層。
- 拼圖、南瓜雕刻、沙雕、逗貓執行時請不要移動滑鼠。
- 「遊戲解析度」預設自動偵測（讀取遊戲視窗大小）；偵測不準時可手動指定。
- 遊戲內的「介面縮放」目前只支援 100%。
- 穩定的解析度是 1600×900，其他解析度沒有經過大量測試，可能認不到圖示或點擊位置不準。

### 模擬器模式

1. 在模擬器設定中開啟 ADB（BlueStacks：開啟「Android 偵錯橋 (ADB)」）。
2. 到「設定」分頁的「背景設定」，填入「ADB 路徑」（設定頁內有安裝說明）與裝置位址。
   - 「模擬器」選單可一鍵填入常見位址：BlueStacks、雷電是 `127.0.0.1:5555`，MuMu 12 是 `127.0.0.1:16384`，MuMu 6 是 `127.0.0.1:7555`，夜神是 `127.0.0.1:62001`。
   - 不確定位址時，先開啟模擬器，再按「ADB 裝置位址」旁的「自動偵測」，程式會找出執行中的模擬器並填入。
3. 模擬器的穩定解析度是 1280×720。
4. 釣魚的「吃食物」需要輸入中文，程式會在第一次吃食物時自動把內附的 [ADBKeyBoard](https://github.com/senzhk/ADBKeyBoard)（GPL-2.0，未修改）安裝到模擬器，並自動切換輸入法，不用手動安裝。

模擬器容易卡頓，可能造成操作失敗或點錯，請斟酌使用。

## 設定

- 每個設定欄位旁都有「還原預設值」按鈕可單獨還原；設定分頁最下方的「還原設定值」可全部重置。
- 停止鍵可以是單鍵（`F8`）或組合鍵（`ctrl+shift+q`，用 `+` 連接）。
- 抓不到圖示時，到「比對設定」把嚴格度調成寬鬆；常常誤判則調成嚴格。
- 設定存在程式旁邊的 `config.ini`，更新程式不會被覆蓋。
