# 設計決策紀錄

記錄「為什麼這樣做」。README 只寫使用者需要知道的事，行為細節與取捨放這裡。

## 釣魚

- **香水**：只看畫面圖示、不看計時。開始時先看有沒有綠色香水圖示；回主畫面後圖示連續消失約 4～6 秒才補噴（自己噴的香水已過期時約 0.6～1.2 秒），補噴前再重新截圖確認，避免閃爍或偶爾認不出來就誤噴。拋竿中看不到圖示，但有香水魚會很快上鉤；連續拋竿超過 40 秒沒釣到，收竿回主畫面確認。噴兩次仍看不到圖示就停止並通知。
- **誘魚器**：沒有圖示可判斷，依間隔（預設 63 秒）丟。勾選 `fishingSkipTail` 時改看水面魚尾光柱：有魚尾 = 效果中不丟，連續看不到才丟（水面染成紫粉色時，用色相補抓青白色光柱）；連續丟了仍看不到魚尾，自動改回照間隔。
- **定時項目等收竿**：拋竿中背包 (B) 與工具欄 (T) 打不開，所以到期後等魚釣起、竿子收回來才執行。
- **隨機延後**：避免完全定時。延後上限為間隔的 10%；香水、誘魚器有持續時間（2 分鐘、1 分鐘），上限改為「間隔 − 持續時間」。
- **背包**：第一次選好「釣魚用品」後順便開啟遊戲的「下次開啟背包保持該結果」；要搜尋食物時先按「結束篩選」回完整清單。此遊戲設定會一直開著。
- **卡滑鼠**：遊戲有時會卡住滑鼠讓視角跟著轉，所以開始時與每次操作背包、工具欄、拋竿前，先在畫面上方中間左右鍵各點兩下（僅前景）。
- **拋竿鈕**：釣竿造型不同，鈕內圖案因人而異。在主畫面時記下拋竿鈕目前樣子，之後用它判斷是否拋竿中；要拋竿時就算比對不到也直接點固定位置。
- **背景定時**：誘魚器效果前景帳號也吃得到，所以由背景丟時建議取消前景的「定時丟誘魚器」。

## 食物

- 只在看到「體力不足，吃點東西吧」提示時才吃，吃到飽食度達設定值（預設 99%）；不定時吃，也不為了看飽食度特地開背包。飽食度用 OCR 讀體力條數字（`tools/ocr.py`）。
- 星級：1～5 指定、`14` = 0-4 星（跳過 5 星）、`0` = 不限（0-5 星）。舊版 `FoodBan5` 設定會自動換算。
- **保留最後一次不吃**：同名同星級的食物每一份各佔一格、各有剩餘次數；某格只剩最後一次就往下一格找，全部都只剩最後一次（或找不到）才放棄並通知。放棄時採集停止腳本，釣魚等下次提示再試。
- 需輸入中文：模擬器用內附的 ADBKeyBoard，第一次吃食物時自動安裝並在輸入前後切換輸入法。

## 採集

- **人味**：每輪等待 = 重生基準 + 0.5～4.5 秒，約 1/8 機率再多分心 4～15 秒；按下前有隨機反應時間，連按間隔與按住時間隨機。
- **鎖定食物**：採集幾乎不碰背包其他東西，第一次搜尋食物時開啟「保持結果」，之後開背包直接停在該食物；若沒停在預期結果，自動改回完整搜尋。
- **維修盒間隔自動計算**：維修盒每秒回復 3%、持續 17 秒（約 51% 耐久），配合每輪次數與定時時間算出剛好用完一個回復量的間隔（耐久 200、每輪 1 次、2 分鐘一輪 ≈ 204 分鐘）。
- **工具耐久耗盡**：按完互動鍵後偵測畫面上方「工具耐久耗盡，請使用維修盒」，只比對白色字形（`templates/gather/toolBroken.png`），立刻丟維修盒；沒勾丟維修盒或連丟 3 次仍耗盡就通知並停止。關閉丟維修盒時介面會先跳出確認（關閉後耐久耗盡不會修）。「離開現在的位置後再丟」會在丟之前先往後退一步（前景按住 S 0.6 秒、模擬器把搖桿往下拉），丟完（成功失敗都一樣）再走同樣時間的 W / 把搖桿往上推走回原位（走路距離有誤差，不一定剛好回到原位）。
- **開始前檢查維修盒**：打開背包篩選「維修盒」（只看木頭材質），用 `templates/digits` 字形辨識數量並預估可執行到何時；6 與 8 偶爾混淆，所以是「預計」，讀不出來不影響執行。
- **倒數圖示**：採完後原地出現倒數圖示（植物 `respawnPlant.png`、木頭 `respawnWood.png`，兩種都認）。連按途中看到就不再按，避免揮空氣。
- **多久沒採到東西就停止**：兩個跡象都沒看到才計時——倒數圖示、畫面上方灰白圓角「獲得物品」氣泡（只認外形，不看物品名稱）。任一出現就重新計時。分鐘數須大於定時時間的 2 倍。
- **前景只截遊戲視窗**：避免視窗外內容誤判（釣魚、料理維持整個螢幕）。

## 其他

- **通知**：需要處理的狀況除寫日誌外，也跳 Windows 桌面通知並閃爍工作列圖示（勿擾模式會吸收通知，閃爍仍有）。
- **懸浮日誌**：置頂、半透明、不搶焦點、不進工作列、不會被截進比對畫面；拖曳後記住位置。上次執行紀錄存在 `config.ini` 的 `lastRun…`。
- **設定旁的圖示**：道具圖示與閥值縮圖取自 `templates`，方便辨認。
